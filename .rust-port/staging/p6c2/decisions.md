**P-321. Agent metadata reaches the model; supersedes the "not wired" notes in P-304 and P-317.** TS `Agent.agentMetadata` is `{ sessionId }` only with a session manager attached, and is sent with every model call (`agent/agent.ts:540-541,2642`) and every context manager summary (`context-manager/strategies/offload/summarize.ts:444`). Choice: `LocalAgent` stores `agent_metadata: Option<AgentMetadata>` with a public `agent_metadata()` getter and a crate-internal setter; `Agent::new` sets it next to the session id when a session manager is configured (the manager's id is fixed at construction, so the stored value equals TS's computed getter). `Agent::session_id()` and `Agent::agent_metadata()` are new public getters (TS `sessionId`, `agentMetadata`). The loop's `ModelTerminal` copies the metadata into `ModelRequest.agent_metadata`; `SummarizeStrategy::summarize_options` copies it into `SummarizeOptions.agent_metadata`, from where `summarize_with_stream` already forwarded it. `ToolAgent` has no getter (no TS consumer reads it from a tool). Files: `src/types/agent.rs`, `src/agent/agent.rs`, `src/agent/run.rs`, `src/experimental/context_manager/strategies/offload/summarize.rs`.
