| Intervention actions a gate ignores | Any action can be returned from any lifecycle method; one without effect logs `<action> has no effect` | Each gate has its own action type, so such an action doesn't compile | Illegal actions can't be expressed (section 12, Phase 7) |
| Intervention override detection | Hooks are registered only for the lifecycle methods a handler overrides | All five gate hooks are registered when any handler is configured; default methods proceed | A trait can't detect overrides; outcomes are identical |
| A failing `transform` closure | `apply()` throwing goes through the handler's `onError` | The closure returns `()` and can't fail | Transform is an infallible closure on the event |
| An intervention handler that pauses the agent | `event.interrupt()` throws `InterruptError`, which skips the rest of the handler and the remaining handlers | `event.interrupt(..)` returns `None`; the handler returns, its action is ignored and the remaining handlers are skipped | Hook interrupts are collected on the event (P-49) |
| `HumanInTheLoop` classifier result that isn't an object with a boolean | Logged as malformed; approval required | Can't occur: the classifier returns a typed `ClassifierResult` | Typed API |
| `HumanInTheLoop` LLM classifier with no model | Throws `LLM risk classifier has no model ..` | Can't occur: the agent's auxiliary model falls back to its model | `aux_model()` always returns a model |
| `CedarAuthorization` principal resolver input | `invocationState` is a string-keyed record | The typed `InvocationState` map (`state.get::<T>()`) | Rust's invocation state is typed |
| `CedarAuthorization` policy parsing | Policy text is re-parsed by the WASM engine on every call | Parsed once at construction and on `reload` | Same decisions; avoids re-parsing |
| Cedar engine error wording | Messages come from `@cedar-policy/cedar-wasm` | Messages come from the `cedar-policy` crate's `Display` (same engine; the prefixes `Invalid Cedar policy: `, `Cedar policy validation failed: `, `Cedar evaluation failed: `, `Access denied by Cedar policy` and `Schema generation failed: ` are TS's) | Different bindings over the same engine |
