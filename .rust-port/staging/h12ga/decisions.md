# h12ga decisions (pending)

**P-1150. `SharedSource::into_arc` is public (SDK).** Context: review finding api-21; the harness options builder is to take a plugin the way `AgentBuilder::plugin` does (`impl Into<SharedSource<dyn Plugin>>`: a value, an `Arc` of one, an `Arc<dyn Plugin>`). `SharedSource` and its `From` impls are public, but the only way to take the `Arc` out was `pub(crate)`, and the harness cannot write the same three `From` impls for a type of its own (`impl<T: Plugin> From<T>` and `impl From<Arc<dyn Plugin>>` overlap outside the crate that owns `Plugin`). Options: (a) make `into_arc` public; (b) a harness setter that takes only `Arc<dyn Plugin>`, which leaves `.plugin(Todos::default())` not compiling. Choice: (a), one line, additive. Files: `strands-rs/strands/src/agent/config.rs`.

**P-1151. `HarnessAgentOptions::tools` and `plugins` are bon builder fields, declared first in the struct.** Context: review finding api-21, decision #32, section 11 item 42. bon setters can be called once, so "`.tools(..)` extends" needs `#[builder(field)]` members with hand-written methods, as `AgentConfig` has; bon requires such fields before the other members, so the two fields moved to the top of the struct (a struct literal is unaffected; `Debug` prints them first). The builder has `.tool(..)`, `.tools(..)`, `.plugin(..)` and `.plugins(..)`. `.plugins(..)` takes `impl IntoIterator<Item = impl Into<SharedSource<dyn Plugin>>>`, which is wider than the SDK's `plugins` (`Arc<dyn Plugin>` items only): `.plugins(vec![Todos::default()])` is the form the finding asks for, and a list of `Arc<dyn Plugin>` still compiles. Files: `harness-rs/strands-harness/src/agent.rs`.
