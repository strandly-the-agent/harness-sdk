# p10fixa staged decisions

**P-700. A dropped `AgentStream` ends its telemetry at the drop.** `Agent::abandon` ends the open `chat` span, the meter cycle (`Meter::end_open_cycle`, the meter now keeps the open cycle's start), the cycle span and the agent span with OK status, the end time and the accumulated usage, as the TS `finally` blocks do when the consumer closes the iterator. The `execute_tool` span of a running tool is held by an `OpenToolSpan` guard in `ToolTerminal::stream`, which ends the span and the tool metric (no result, `success: false`, the TS `finally` values) when the stream or its aborted task is dropped; the guard may run after the cycle span ended. Files: `agent/run.rs`, `telemetry/meter.rs`, `tools/executors/executor.rs`.

**P-701. Detached memory drivers are spawned without the caller's span.** `ExtractionCoordinator` and the detached `MemoryManager::add_entries` writes no longer call `in_current_span()`: a held `tracing` handle keeps the span and its parents unexported until the save ends, and both `memory.extract` (linked to the caller) and the detached `memory.add` are root spans. Files: `memory/extraction/coordinator.rs`, `memory/memory_manager.rs`.

**P-702. One value per span attribute key.** A `trace_attributes` key replaces the span's start attribute of that key (`LocalTracer::record_start` skips the span's value), and the keys a span sets after its start (`keys::SET_AFTER_START`) are never taken from `trace_attributes`, on any span. TS keeps such a trace attribute on spans that never set the key; Rust can't replace a recorded attribute and must not export a key twice. File: `telemetry/tracer.rs`.

**P-703. `MemoryTracer::end_search` takes the query.** Under `gen_ai_span_attributes_only`/Langfuse the `memory.search` span gets its single `content` attribute at the end: the results, or the query when the search failed (the value TS ends with in each case). Crate-private signature change; callers in `memory/memory_manager.rs`. File: `telemetry/tracer/memory.rs`.

**P-704. The cycle span ends with the error for a cancel and an interrupt.** `Stop::Cancelled` ends `execute_agent_loop_cycle` with `Agent invocation cancelled` and `Stop::Interrupted` with the TS `InterruptError` text, as TS `closeCycle(error)` does; the agent span still ends OK with the cancelled or interrupted result. The agent span now starts before the structured-output tool is registered. File: `agent/run.rs`.
