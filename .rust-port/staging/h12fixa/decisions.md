**P-990. `ToolCallOutcome::HookCancelled(ToolResultBlock)` tells a hook cancel from a tool's own error result.** `ToolAgent::call_tool` returned a `BeforeToolCallEvent` cancel as `ToolCallOutcome::Result` with an error status, so the harness `programmatic_tool_caller` gave the guest `Tool '<name>' error: <message>` where TS (`gateInnerCall` throws inside the `try` whose `catch` adds the prefix, `harness-ts/src/tools/programmatic-tool-caller.ts:278-287,358`) gives `Failed to execute tool '<name>': <message>` (review finding parity-a1). The enum is `#[non_exhaustive]`, so the new variant is additive; it carries the error result after the `AfterToolCallEvent` hooks. SDK public API change made for the harness; the SDK crate's own caller of `call_tool` results is its tests only.
