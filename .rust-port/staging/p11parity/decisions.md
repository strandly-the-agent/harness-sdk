# Decisions (track p11parity)

**P-580. `agent.context-manager.test.ts` is declared in the title map instead of renaming.** Its Rust tests are in `src/experimental/context_manager/tests.rs`, which this track must not edit, so the eight TS cases that share a test per construction are declared in the map against the existing names. Two cases were not asserted by any test (`when "agentic" > creates a ContextManager instance`, `registers the instance as a plugin`); they are ported in the new `agent::run::tests::context_manager`. When the context-manager track is done, the eight declared cases can become renamed or split tests. Files: `strands-rs/strands/src/agent/run/tests/context_manager.rs`, `strands-rs/docs/test-title-map.json`.

**P-581. `agent.interrupt.test.ts` is 30/32.** The `before_tool_call_hook` and `before_tools_hook` test modules are renamed after their `describe` blocks (`interrupt_from_before_tool_call_event_hook`, `interrupt_from_before_tools_event_hook`), four tests are renamed to their TS titles, `does_not_fire_after_tool_call_event_when_a_hook_or_tool_interrupts` is split into the two TS cases, and five cases are ported (`BeforeToolCallEvent` stop reason, several `BeforeToolCallEvent` hooks, a pure interrupt-response resume, `InterruptEvent` on the stream). `allows pure interrupt response arrays without error` was counted as not applicable; it applies (the typed `Vec<InterruptResponse>` input is the pure array). Files: `strands-rs/strands/src/agent/run/tests/interrupt.rs`.

**P-582. `agent.test.ts` is 128/147; the `the row:` gaps of this spec are resolved.** The stale gap entries (P-544) are removed where a test of the TS name already existed (`sessionId`, `agentMetadata`, offloading), declared where a differently named test covers the case (consumer break: `dropping_mid_tool_aborts_the_tool_and_keeps_history_re_invokable`; provider switch: `allows_model_change_to_persist_across_invocations`; `rejects a ModelRouter`: `aux_model_rejects_a_model_router`; direct shutdown flush: `agent_shutdown_flushes_memory`), and ported otherwise: the four the row listed (traces after a mid-run error, system prompt from block instances, `agent.model` identity, aux model reassignment), three `BedrockModel` id cases, the two structured-output cases across an interrupt resume, the injected block case and the shutdown no-op. The two `await using` cases are TS-only (no async drop). `is_reassignable_at_runtime` leaves out the id-string step: `Agent::set_aux_model` takes a model, and the id form is `AgentBuilder::aux_model`. Files: `strands-rs/strands/src/agent/run/tests.rs`, `strands-rs/strands/src/agent/run/tests/structured_output.rs`.

**P-583. An `it.each` case that Rust ports as one test per value is declared against the first of them.** The checker counts an `it.each` once and the map holds one name per case, so the remaining per-value tests show as Rust-only in `--report` (`mcp/client.test.ts`: `..._continue_on_error_{false,true}`, `elicitation_handler_returns_{decline,cancel}_result`, `..._during_refresh_{request,name_length}`). Where Rust has a single value the test takes the template name (`throws_an_actionable_error_with_continue_on_error`). Files: `strands-rs/docs/test-title-map.json`.

**P-584. Titles with operators are renamed by the rule even though the operator is lost.** `throws on compressionThreshold <= 0` is `throws_on_compression_threshold_0`, `> 1` is `..._1`, `(messages.length - windowSize)` is `..._messages_length_window_size`, `expands ~ to home directory` is `expands_to_home_directory`. The names stay distinct within their specs. The same holds for `maps_signal_termination_to_128_signal_number` (`128 + signal number`), the `%s`/`%o` templates (`reports_failure_of_via_error_and_non_zero_exit`, `offset_limit_must_be_integers_rejects`) and the two sleep cases that keep TS wording for what runs on the injected sleeper (`returns_the_expected_message_after_a_real_short_sleep`, `drives_set_timeout_with_the_requested_duration_in_ms`). One exception: `excludes . and .. entries` would be `excludes_and_entries`, which says nothing, so `excludes_dot_and_dot_dot_entries` keeps its name and is declared in the map. Files: `strands-rs/strands/src/conversation_manager/tests.rs`, `.../sliding_window_conversation_manager/tests.rs`, `strands-rs/strands/src/mcp/tests/config.rs`, `strands-rs/strands/src/sandbox/tests.rs`, `strands-rs/strands/src/vended_tools/{python_repl,read,sleep}/tests.rs`.

**P-585. The two-level subagent delegation test runs with the `auto` context manager.** `delegates_two_levels_deep` ran without `contextManager: 'auto'` because the context manager didn't exist when it was ported (P-282). It now builds the parent with `ContextManagerPreset::Auto`, as the TS case does, and has the TS title. Files: `strands-rs/strands/src/vended_tools/subagent/tests.rs`.

**P-586. Combined metadata and error tests of the bash tool are split into their TS cases.** `has_correct_tool_name_description_and_tool_spec` becomes `has_correct_tool_name`, `has_description` and `has_tool_spec`, and the combined error-class test becomes `bash_timeout_error_has_correct_properties` and `bash_session_error_has_correct_properties`, with the same assertions. The two `module exports` cases are declared against them: a Rust export is checked by the `use` the test compiles with. The notebook's three `throws error for non-existent notebook` tests take their `describe` as a prefix (P-541) instead of the `_on_read`/`_on_replace`/`_on_clear` suffixes. Files: `strands-rs/strands/src/vended_tools/bash/tests.rs`, `strands-rs/strands/src/vended_tools/notebook/tests.rs`.
