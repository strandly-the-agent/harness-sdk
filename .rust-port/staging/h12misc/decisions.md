**P-980. The shell probe cache is a `ShellCache` each consumer owns.** TS `sandbox.ts` keeps one module-wide `WeakMap<Sandbox, SandboxShell>`, so a sandbox is probed once per process whichever tool asks. Rust has no global: `ShellCache` holds `Weak<dyn Sandbox>` entries and each tool or plugin that asks owns one (P-852 says so for `web_fetch`), so a sandbox is probed once per consumer. The answers are the same; only the number of probe commands a sandbox sees differs (one per consumer instead of one). The three `sandbox.test.ts` cases are ported in `sandbox/tests.rs` against one `ShellCache`. Alternative: a `static` cache shared by the crate, which would match the TS probe count but add process-global state the port avoids elsewhere.

The agent gets the tools from `client.list_tools()`, as the TS case does.
