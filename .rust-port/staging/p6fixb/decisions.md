# p6fixb decisions (P-620..)

**P-620. TS-internal context manager items are crate-private; corrects P-310.** Review finding api-6: P-310 listed items as public that TS marks `@internal` and exports from neither `index.ts` nor `experimental/index.ts`. Choice: `pub(crate)` for `Stash::new` (old public `Stash::new(storage, session_id, agent_id, custom_namespace)`; a stash is only created by a `ContextManager`), `Stash::clear_session`, `Stash::take_snapshot`, `Stash::load_snapshot`, `EmergencyTruncateStrategy` (and its `NAME`, `new`), `BLOCK_SUMMARY_INSTRUCTIONS`, `DROPPED_MARKER`, `RETRIEVAL_TOOL_NAME` and `STRATEGY_PRESET_NAMES` (which also takes the `[StrategyPresetName; 4]` length out of the public API, finding api-7). `Stash` keeps what a custom `ContextStrategy` calls: `store`, `refs_for`, `store_message`, `retrieve`, `list`, `delete`, `clear`, `storage_type_name`, `is_durable`. P-310 also says the `strategies::offload::{base, drop, emergency, summarize, truncate}` modules are public; they are private and their public types are re-exported from `strategies::offload` and the `context_manager` root. `strands::experimental` now also re-exports `TruncateConfig`, `SummarizeConfig` and `PreviewMode` (TS `experimental/index.ts:17-18`; api-8). TS reference: `context-manager/stash.ts:68`, `strategies/offload/base.ts:544`, `summarize.ts:40`, `drop.ts:4`, `retrieval-tool.ts:6`. Files: `src/experimental.rs`, `src/experimental/context_manager.rs`, `src/experimental/context_manager/{stash,presets,retrieval_tool}.rs`, `src/experimental/context_manager/strategies/offload/{drop,emergency,summarize}.rs`, `src/experimental/context_manager/strategies/offload.rs`.

**P-621. Whole-history token counts go through `ModelProxy`; corrects P-317.** P-317 kept direct `model.count_tokens` calls because the Rust `ModelProxy` had no `count_tokens`; it has one now (`models/model_proxy.rs`). Choice: `ModelProxy::new(&*model).count_tokens(..)` at the three whole-history sites (TS `context-manager/context-manager.ts:212,232`, `strategies/offload/base.ts:560`), so summary and injected blocks are counted in the form the request sends; per-block counts stay direct as in TS (`base.ts:463,511`). The strategy loop sets `any_acted` before the recount (TS `context-manager.ts:229-233`). Files: `src/experimental/context_manager.rs`, `src/experimental/context_manager/strategies/offload/emergency.rs`.

**P-622. `StashOption` and `MemorySetting<T>` stay two shapes.** Review finding api-16. TS `stash?: StashConfig | boolean` treats `true` as the default config, so `StashOption::{Enabled(StashConfig), Disabled}` loses nothing and `From<bool>` maps `true` to `Enabled(StashConfig::default())`. `MemorySetting<T>::{Off, On, Config(T)}` (P-351) keeps `On` as its own variant for the three memory unions. Choice: keep both; `ContextManagerConfig::stash` is now `#[builder(into)]` like the `MemoryManagerConfig` fields, so `.stash(false)` and `.stash(StashConfig { .. })` compile. `ContextStrategyEntry` gains `From<Arc<S>>` (api-11) and `ContextManagerPreset` gains `as_str` and `Display` (api-14). Files: `src/experimental/context_manager.rs`.

**P-623. `OffloadConditions::threshold` is `Option<u64>`; corrects P-310.** Review finding api-12. TS types it `number` and documents it as a token threshold (`context-manager/strategies/offload/base.ts:55-56`); AGENTS.md maps TS counters to `u64`, and `TruncateConfig::preview_tokens` is already `Option<u64>`. Choice: `threshold: Option<u64>` (old `Option<f64>`); `utilization` and `preserve_recent` stay `f64` (fractions in TS). The TS `finiteOrUndefined` guard and a negative threshold have no Rust form for this field: token counts are integers, so `tokens > 2500.5` and `tokens > 2500` agree, and a negative threshold only differs from `0` for a block of zero tokens. The `threshold (N) must be greater than previewTokens (M)` text is unchanged. Files: `src/experimental/context_manager/strategies/offload/{base,truncate}.rs`, `src/experimental/context_manager.rs`, `src/experimental/context_manager/presets.rs`.

**P-624. Storage backends: `with_namespace`, no inherent `search`; corrects P-300.** Review finding api-18. P-300 gave `InMemoryStorage` and `LocalFileStorage` inherent `namespace(&self, prefix) -> Result<Self>` and `search(&self, query) -> Result<Vec<StorageSearchResult>>` beside the trait methods `Storage::namespace -> Option<Result<Arc<dyn Storage>>>` and `Storage::search -> Option<Result<..>>`, so the same call changed type between a concrete backend and `S: Storage`. Choice: the inherent view constructor is `with_namespace(&self, prefix) -> Result<Self>` (old name `namespace`; it keeps the concrete type, which `clear()` and `base_dir()` need), and the inherent `search` is removed (callers use `Storage::search`, which returns `Some(..)` for both backends). TS reference: `storage/in-memory-storage.ts`, `storage/local-file-storage.ts` (`namespace`, `search`). Files: `src/storage/{in_memory_storage,local_file_storage}.rs`.

**P-625. `ContextManager` is a cheap-clone handle; corrects P-310.** Review finding api-17. Choice: `#[derive(Clone)] pub struct ContextManager { inner: Arc<Inner> }` like `SessionManager` and `MemoryManager`; `Agent::context_manager() -> Option<&ContextManager>` (old `Option<&Arc<ContextManager>>`), `ContextManagerStrategy::Manager(ContextManager)` (old `Manager(Arc<ContextManager>)`), `ContextManager::from_strategy -> Result<Option<ContextManager>>` (old `Option<Arc<Self>>`); `From<Arc<ContextManager>> for ContextManagerStrategy` is removed (`From<ContextManager>` stays). Clones share state, so the TS "instance is used as is" cases assert shared state instead of pointer identity of the plugin `Arc`. The config builders of the storage, session and context manager configs are re-exported with public state modules (api-3): `InMemoryStorageConfigBuilder`/`in_memory_storage_config_builder`, `LocalFileStorageConfigBuilder`/`local_file_storage_config_builder`, `SessionManagerConfigBuilder`/`session_manager_config_builder`, `ListSnapshotIdsOptionsBuilder`/`list_snapshot_ids_options_builder`, `OffloadConditionsBuilder`/`offload_conditions_builder`, `SummarizeConfigBuilder`/`summarize_config_builder`, `TruncateConfigBuilder`/`truncate_config_builder`, `ContextManagerConfigBuilder`/`context_manager_config_builder`, `StashConfigBuilder`/`stash_config_builder`. Files: `src/experimental/context_manager.rs`, `src/agent/agent.rs`, `src/storage.rs`, `src/session.rs`.

**P-626. TS `OffloadStrategyBuilder` has no Rust type.** Review finding api-9. TS types the return of `Offload.drop/truncate/summarize` as the interface `OffloadStrategyBuilder` (a `ContextStrategy` with `when(conditions)`; `context-manager/strategies/offload/base.ts:73`, exported at `index.ts:331`) because the concrete classes are internal. Choice: the Rust builders return the concrete public types `DropStrategy`, `TruncateStrategy` and `SummarizeStrategy`, each with an inherent `when(OffloadConditions) -> Result<Self>` and a `ContextStrategy` impl, so no trait with that name exists; a caller that needs one type uses `Arc<dyn ContextStrategy>` or `ContextStrategyEntry`. Files: `src/experimental/context_manager/strategies/offload.rs`.
