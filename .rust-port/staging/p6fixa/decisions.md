**P-600. `MemoryManager::flush` also waits for detached `add_memory` writes.** TS `flush` waits only for the extraction coordinator; a write accepted with `waitForWrites: false` is a floating promise that the Node event loop keeps alive (`memory/memory-manager.ts:687-691`). A Tokio runtime that stops drops a spawned task, so an accepted entry could be lost after `Agent::shutdown()`. Choice: the manager counts detached writes (a `tokio::sync::watch` counter decremented by a drop guard, so a panic or a dropped task also counts down) and `flush` waits for zero after flushing the coordinator. The tool still answers `{"accepted": n}` at once. Files: `src/memory/memory_manager.rs`.

**P-601. A panicking store or extractor is a failed save.** TS settles a store's save chain on any throw (`memory/extraction/coordinator.ts:233-249`). The Rust chain is a `futures::future::Shared`, which a panic poisons for every later save and for `flush`. Choice: the save runs under `catch_unwind`; a panic is the error `memory store save panicked`, with the same rollback, failure count and back-off as a returned error. Files: `src/memory/extraction/coordinator.rs`.

**P-602. `AgentSkills` URL sources stay pending until fetched; a replaced set drops the fetches it started.** The pending URLs are no longer taken out before the fetch (a dropped `ready()` future lost them); they are cleared when the results are stored. `Resolved` has a generation that `set_available_skills` bumps, and `ready()` discards results of an older generation and fetches the current set's URLs (TS inserts into the map of the `_resolveSkills` call that started the fetch, `vended-plugins/skills/agent-skills.ts:219-241`). Files: `src/vended_plugins/skills/agent_skills.rs`.

**P-603. The `SKILL.md` YAML subset gains block scalars, nested mappings and the YAML double-quote escapes; amends P-384.** Parsed now: `|` and `>` block scalars with the `-`/`+` chomping indicators and an indentation digit (folding as the `yaml` package does: a single break between text lines is a space, blank lines are breaks, breaks around more-indented lines are kept), mappings nested to any depth, a block sequence at the key's own indentation, and the escapes `\0 \a \b \t \n \v \f \r \e \N \_ \L \P \xNN \uNNNN \UNNNNNNNN`. Expected values come from TS `Skill.fromContent` (`src/vended_plugins/skills/skill/frontmatter_cases.json`, 18 cases), and the 11 `SKILL.md` files plus 5 extra cases of the parity review (`skill_real_ts.json`) now give the TS result. Still not supported, and skipped: multi-line plain and quoted scalars, anchors, tags, flow mappings, sequences of mappings. Files: `src/vended_plugins/skills/skill.rs`.
