**P-521. The quick start turns the printer off; P-521 amends P-84.** Section 13's headline example prints `{result}` after `invoke` and each text delta of `stream`, but an agent's printer is on by default (as in TS), so running the verbatim example against Bedrock printed every answer twice (and interleaved the streamed deltas with the printer's). `examples/basic.rs`, the crate-level quick start doctest and the README quick start therefore add `.printer(false)` to the builder and a `println!()` after the stream loop, and are otherwise the section 13 text (with the let-chain of P-84). The three are byte-identical from the first `use` line. Alternative for the lead: keep the printer on and drop the example's own printing, which is closer to the TS quick start but no longer shows `AgentStreamEvent`. Files: `strands/examples/basic.rs`, `strands/src/lib.rs`, `README.md`.

**P-522. Section 13 snippets against the real API.** Every SDK snippet of section 13 compiles as an example or a doctest with these differences, none of which changes the public API: (a) the mapping table's `FunctionTool::builder(..)` is `FunctionTool::new` / `FunctionTool::typed` / `with_input_schema` (P-51); the `tools` example and the crate docs use those names. (b) "an order option" on hook registration is the `_with` form taking `HookCallbackOptions { order }` (`add_hook_with`, `add_async_hook_with`, `add_hook_impl_with`), not an argument of `add_hook`; the `hooks` example shows `HookOrder::DEFAULT - 1`. (c) The cancel snippet compiles as written, but `CancelHandle::cancel` only stops the invocation that is running, and a running tool finishes unless it watches `ctx.cancel_signal()` (as in TS); the `hooks` example therefore cancels 200 ms into a run whose tool selects on `ctx.cancel_signal().cancelled()`, and prints `Cancelled`. (d) `StateStore::get::<T>` returns `Result<Option<T>>`; the `tools` example uses `?` where section 13 discards the value. (e) The `AnthropicModel` snippet is the `anthropic` example with `Agent::new(AgentConfig { model: Some(..build()?.into()), .. })` as written, but with the model id `claude-sonnet-4-6` (the provider's default id in `models/defaults.rs`) instead of `claude-sonnet-5-5`. (f) `InvokeOptions::cancel_signal` is a public field (set with a struct literal or `InvokeOptions::builder().cancel_signal(..)`), not a method. (g) The harness snippet is Phase 12; its SDK part, the `while result.stop_reason() == StopReason::Interrupt` resume loop with `Vec<InterruptResponse>`, is a doctest in the crate docs that runs against `MockMessageModel` with a tool that calls `ctx.interrupt("confirm".into())?`. Files: `strands/examples/*.rs`, `strands/src/lib.rs`.
