# h12gc decisions

**P-1180. The environment-context case of `e2e.test.ts` runs live through a sandbox with its own working directory (replaces P-1094 for this case).** TS calls `process.chdir` to a temporary directory; Rust tests never call `set_current_dir`. `NotASandboxLocalEnvironment` has no public working-directory setting (`with_base_dir` is a `pub(crate)` test seam of the SDK), so `tests/live_e2e.rs` defines `HostIn`, a `PosixShellSandbox` that delegates `execute_streaming` to `NotASandboxLocalEnvironment` with `ExecuteOptions::cwd` set to the temporary directory when the caller names none, and passes it as `agent_config.sandbox`. The file operations of `PosixShellSandbox` are shell commands, so they resolve relative paths there too. No SDK change. The environment plugin stays out of the six-tool and caching live tests, as P-1094 records. PENDING: whether `NotASandboxLocalEnvironment` should get a public working-directory option (TS has none).

**P-1181. The `docsrs` cfg is used, not dropped (api-6).** `harness-rs/strands-harness/Cargo.toml` passes `--cfg docsrs` to rustdoc on docs.rs; `lib.rs` now has `#![cfg_attr(docsrs, feature(doc_cfg))]`, as the SDK crate does. With it, rustdoc marks every `#[cfg(feature = ..)]` item by itself, so no `doc(cfg(..))` attribute was added to the two Exa functions or the `From<IndexMap<..>>` impl (checked with `--cfg docsrs`: all three pages carry the `mcp` note). Dropping the `rustdoc-args` line instead would have meant an edit in a `Cargo.toml`, which another track owns.

**P-1182. The two-cell `DIVERGENCES.md` row for P-958 is removed rather than completed (api-6, parity-10).** The file already has a four-cell row for the same difference (`createHarness`: recognising a consumer plugin that stands in for a built-in one, P-958 and P-1142), and the two-cell text ("recognised by plugin name, not type") stopped being true for `Todos` and `EnvironmentContext` with P-1142. The other four rows have their four cells.

**P-1183. The `create_harness` doctest and the README usage example call `.mcp_servers("./mcp.json")` before the conversion exists on this branch (api-6).** The brief asks for the PROMPT.md section 13 snippet written against the `From<&str>` conversion of finding api-1 (track `h12ga`). Until that commit is integrated, the doctest `agent::create_harness` fails to compile (`E0277`) and `cargo test -p strands-harness` exits 101 on it; every other test and doctest passes. With `impl From<&str> for McpServersOption` added locally (not committed), the doctest compiles.
