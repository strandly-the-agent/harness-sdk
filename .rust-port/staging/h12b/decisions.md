**P-1070. The harness has no `internal` module; the CLI plumbing stays `pub(crate)`.** Context: TS `harness-ts/src/internal.ts` (marked `@internal`) is a second package entry, `@strands-agents/harness/internal`, that re-exports `normalizeHarnessAgentConfig`, `resolveModel`, `resolveMemory`, `resolveInterventions`, `resolveBuiltinTools`, `enabledBuiltinTools`, `builtinToolConfig` (and `EFFORT_LEVELS`, the default dirs, `webSearchExplicit`, `webSearchMode`, `BuildAgent`) for the TypeScript CLI. Choice: (c). PROMPT.md section 7.1 maps `@internal` to `pub(crate)` or `#[doc(hidden)]`; section 5 keeps the CLI in TypeScript, so no Rust code outside the crate calls the plumbing, and section 7.4 adds nothing TS users do not have (the TS root does not export it either).
