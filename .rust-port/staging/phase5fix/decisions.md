**P-210. Mantle caches the default chain's credentials.** `aws-config`'s default chain has no cache (`aws-config-1.13.2/src/lib.rs:973-979`), so minting a token per request looked credentials up per request (IMDS, ECS, STS, SSO). TS's token generator uses `fromNodeProviderChain`, which memoizes and treats credentials as expired 5 minutes before `expiration` (`@aws-sdk/credential-provider-node/dist-cjs/index.js:21-60,162`). Choice: a crate-internal `CachedCredentials` (a `tokio::sync::Mutex<Option<Credentials>>`, held across the fetch so concurrent mints share one lookup) wraps the default chain: fetch again only within 5 minutes of `expiry()`, never when there is none; a failed refresh keeps credentials that haven't expired (the JS passive refresh swallows errors).
