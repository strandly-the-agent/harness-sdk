**P-497. `AttributeValue::Str`, not `AttributeValue::String`.** P-483 named the string variant `String`. A public item named `String` defined in a crate's direct dependency makes rustc stop trimming `std::string::String` to `String` in every diagnostic of that crate, which broke the `strands-macros` trybuild case `tests/ui/fail/not_an_event.rs` at the port tip (expected `String`, actual `std::string::String`; visible in `gate_test_all_nofailfast.txt` of the `p6merge` gate, hidden in the main gate behind an earlier failing test binary) and would have changed the compiler output of every application using the SDK. The variant is `Str(String)`; `From<&str>` and `From<String>` are unchanged, and `StringArray` keeps its name (no clash). The alternative, blessing the trybuild expectation, would have recorded the regression instead of removing it. Files: `src/telemetry/tracer.rs`.
