TS gets the tool input from `JSON.parse`, so `1.0` and `1e0` are the number `1` and reach Cedar as a Long (`cedar.ts:180-187`); Rust keeps the `f64` and `Context::from_json_value` / `Entities::from_json_value` reject it.
