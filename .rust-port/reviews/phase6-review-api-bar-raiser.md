1. `src/storage.rs:65-70`: the persisted stash `storageType` comes from `std::any::type_name::<Self>()`. `InMemoryStorage` and `LocalFileStorage` don't override `storage_type_name` (`grep -rn 'fn storage_type_name' src` finds only `storage.rs:66` and the `"Object"` view at `storage.rs:212`), so the wire value that section 10 fixes to the TS class names (`context-manager/stash.ts:82`, written at `src/session/session_manager.rs:283`, compared at `:359`) depends on a string std documents as "intended for diagnostic use", with contents and format "not specified" and output that "may change between versions of the compiler" (https://doc.rust-lang.org/std/any/fn.type_name.html). Fix: override `storage_type_name` in both shipped backends with the literals `"InMemoryStorage"` and `"LocalFileStorage"`; keep the `type_name` default only for custom backends.

2. `src/session/session_manager.rs:94-99`: the sealed `SnapshotTarget` has public methods `local_agent()` and `local_agent_mut()`, so any crate can take `&mut LocalAgent` out of an `Agent`, whose `local` field is `pub(crate)` (`src/agent/agent.rs:75`) and which P-303 says "doesn't expose its `LocalAgent`".
