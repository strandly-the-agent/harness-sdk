# Work in progress from unfinished tracks

Each folder holds `git format-patch` output from a worktree branch that wasn't integrated when it was saved; `BASE` has the base commit and the commit count. Apply on a scratch branch from that base (`git worktree add /mnt/workspace/wt-<track> -b wip/<track> <base> && git -C /mnt/workspace/wt-<track> am /mnt/workspace/harness-sdk/.rust-port/wip/<track>/*.patch`), then cherry-pick onto `feat/rust-sdk` (`.rust-port/tools/cpauto.sh <track>`), fold `.rust-port/staging/<track>/` into the shared logs (`.rust-port/tools/fold.py <track>`; harness tracks stage rows for `harness-rs/docs/`, which `fold.py` does not handle: apply those by hand), and delete the folder here. The briefs are `.rust-port/briefs/run4-<track>.md`. If `/mnt/workspace/wt-<track>` still exists, its branch may hold newer commits than these patches; prefer them.
